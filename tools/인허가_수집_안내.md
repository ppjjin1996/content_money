# 콘텐츠 업종 인허가(개업·폐업) 수집 안내

LOCALDATA 파일 서버(file.localdata.go.kr)는 2026년 포털 통합 이후 접근이 막혀(403), 공공데이터포털 **오픈API**로 받아야 합니다. 인증키가 필요해서 한 번만 직접 신청해 주세요.

## 1. 활용신청 (11개, 자동승인)
[공공데이터포털](https://www.data.go.kr) 로그인 → 검색창에 아래 이름을 넣고 **오픈API** 탭의 항목에서 [활용신청] (개발계정, 활용목적은 '연구/분석' 등)

- 승인 직후에는 키가 활성화되기까지 수십 분~1시간 걸릴 수 있습니다.

## 2. 인증키 넣기
마이페이지 → 데이터활용 → 인증키 발급현황에서 **Decoding 키**를 복사해, 프로젝트 폴더(`데이터시각화`)에 `.datagokr_key` 파일을 만들고 키 한 줄만 붙여넣습니다. (이 파일은 다른 곳에 공유하지 마세요.)

## 3. 실행
프로젝트 폴더에서:

```bash
python tools/collect_licenses.py
```

- 전체 약 1,870회 요청, 15–30분 정도 걸립니다. 중간에 끊겨도 다시 실행하면 이어받습니다(`data/raw_인허가/_pages`).
- 결과
  - `data/raw_인허가/<업종>.csv` — 원자료(전화번호·좌표는 저장하지 않음)
  - `data/15_콘텐츠업종_인허가_개폐업_시도별_연도별.csv` — 대시보드가 읽는 집계
- 끝나면 대시보드 '창업과 소멸' 섹션의 **콘텐츠 업종만 따로 보면.** 카드가 자동으로 채워집니다.

## 집계 기준
- 개업 = 인허가일자 연도, 폐업 = 폐업일자 연도(없으면 인허가취소일자)
- 시도 = 도로명주소(없으면 지번주소) 앞부분. 주소가 비어 있으면 '미상'
- 연말 영업(추정) = 그해 말까지 인허가를 받았고 그해 말까지 폐업하지 않은 업체 수 — 현재 대장으로 거꾸로 계산한 값
