# K-Content Market Pulse — 콘텐츠 시장 대시보드

시도별 콘텐츠 산업의 매출·사업체·창업과 소멸·인허가·지자체 예산·정책 변화를 한 화면에서 비교하는 정적 웹 대시보드입니다.

- **대시보드**: `dashboard/` — 접속 암호 두 갈래: 일반 사용자 초기값 `0000`, 관리자 초기값 `admin0000`. 관리자로 들어왔을 때만 오른쪽 위 '비밀번호 변경'이 보입니다. 바꾼 값은 그 브라우저에 바로 적용되고, 모두에게 적용하려면 내려받은 `auth.json`으로 `dashboard/auth.json`을 바꿔 커밋·푸시합니다.
- **디자인시스템**: `design-system/` (토큰 `tokens.css`, 가이드 `index.html`)
- **데이터**: `data/*.csv` (출처·단위·주의사항은 [`data/README.md`](data/README.md))
- **수집 도구**: `tools/collect_licenses.py` (인허가 오픈API 수집 — 인증키는 저장소에 올리지 않음)

> ⚠️ 접속 암호는 브라우저 안에서만 동작하는 가림막입니다. 공개 저장소이므로 코드와 CSV는 누구나 볼 수 있습니다. 모든 데이터는 공개된 공공데이터입니다.

## 화면 구성
- 상단 고정 필터: **기간(연도 달력)·지역·업종** — 모든 섹션에 적용
- **한눈에**: 17개 시도 실제 경계 지도(8개 지표) + 선택 지역 요약
- 상세 페이지: 매출 · **업종**(장르 순위·추이·지역 특화도) · 지역 · 창업과 소멸 · 예산 · **인구와 수요**(인구·고령화·소득, 1인당 지표) · 정책
- **교차분석**: 두 지표를 골라 17개 시도 산점도·상관계수(r, ρ). 수록 연도가 겹치지 않는 조합은 고를 수 없음
- **보고서**: 영역을 골라 자동 문장·차트·출처가 든 보고서를 만들고 인쇄/PDF 저장 (`dashboard/pages.js`)
- **데이터 소스**: 자료별 출처를 참고문헌 형식으로 정리 (`dashboard/sources.js`)
- 접고 펼치는 상세 섹션: 매출 · 지역 · 창업과 소멸(+콘텐츠 업종 인허가) · 예산(+국비·시도비·시군구비) · 정책

## 로컬에서 보기
```bash
python -m http.server 5174
```
브라우저에서 `http://localhost:5174/` 를 엽니다. (파일을 더블클릭해 `file://`로 열면 데이터를 읽지 못합니다.)

## 데이터 출처
- 국가통계포털(KOSIS): 문화체육관광부·한국콘텐츠진흥원 「콘텐츠산업조사」, 국가데이터처 「기업생멸행정통계」, 중소벤처기업부 「창업기업동향」, 문화체육관광부 「공연예술조사」
- 지방재정365: 「기능별 재원별 세출예산」, 세출예산
- 열린재정: 부처별·단위사업별 결산, 재정사업 설명자료
- 공공데이터포털: 행정안전부 지방행정 인허가 데이터(문화 업종·출판사)
- 국가법령정보센터 법령 연혁, 한국벤처투자 모태펀드 출자사업 선정 결과

통계 해석 주의(조사 개편 시점, 통계표 간 정의 차이 등)는 각 차트 카드 하단과 `data/README.md`에 적혀 있습니다.
